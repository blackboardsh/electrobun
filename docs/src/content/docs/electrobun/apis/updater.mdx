              <p>Electrobun's built-in update mechanism for your app</p>

              
```javascript
// /src/bun/index.ts
import { Updater } from "electrobun/bun";
```


              
```javascript
// /electrobun.config
{
 ...

 "release": {
    "baseUrl": "https://your-release-url"
 }
}
```


## Updating Electrobun Apps

              <p>Electrobun ships with a built-in update mechanism that prefers compact binary patches and falls back to a compressed full application download. Specify the URL where artifacts are stored in `electrobun.config.ts`; a static host such as S3, Cloudflare R2, or GitHub Releases is sufficient.</p>

              <p>For each canary or production build, Hutch creates a flat release `artifacts` folder containing update metadata, patches, and full bundles. Upload that folder to your release host, set `baseUrl`, and use this API to check for and install updates when your app launches, on an interval, or in response to a system tray menu item.</p>

## Methods

### getLocalInfo

              <p>Get the local version info for display in your app or other logic. This will read the `version.json` file bundled with your app.</p>

              
```yaml
const localInfo = await Electrobun.Updater.getLocalInfo();

localInfo: {
  version: string;
  hash: string;
  baseUrl: string;
  channel: string;
  name: string;
  identifier: string;
};
```


### checkForUpdate

              <p>Checks for an update by fetching the `update.json` file from the `baseUrl` for the current channel and platform.</p>

              
```javascript
const updateInfo = await Electrobun.Updater.checkForUpdate();

updateInfo: {
  version: string;
  hash: string;
  updateAvailable: boolean;
  updateReady: boolean;
  error: string;
};
```


### downloadUpdate

              <p>This will initiate a process where it attempts to download patch files and apply them until the patched app matches the current version. If something goes wrong like there isn't a trail of patch files from the user's version to current it will download the latest full version of the app directly.</p>

              
```javascript
await Electrobun.Updater.downloadUpdate();
```


### applyUpdate

              <p>Once the latest version is either patched or downloaded and ready to install you can call `applyUpdate` to quit the current app, replace it with the latest version, and relaunch.</p>

              
```javascript
if (Electrobun.Updater.updateInfo()?.updateReady) {
  await Electrobun.Updater.applyUpdate();
}
```
