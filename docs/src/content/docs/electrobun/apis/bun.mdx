---
title: "Main Process API"
description: "Import Electrobun's TypeScript main-process SDK."
---

The main-process SDK manages application lifecycle, windows, native menus,
updates, and communication with webviews. Cottontail is the default runtime;
the compatibility import path remains `electrobun/bun` for both Cottontail and
Bun main processes.

Named imports are recommended:

```ts
import {
  BrowserWindow,
  ApplicationMenu,
  Utils,
} from "electrobun/bun";

const win = new BrowserWindow({
  title: "My app",
  url: "views://mainview/index.html",
});

ApplicationMenu.setApplicationMenu([
  { label: "File", submenu: [{ role: "quit" }] },
]);

Utils.showNotification({ title: "Application started" });
void win;
```

A default namespace export is also available:

```ts
import Electrobun from "electrobun/bun";

const win = new Electrobun.BrowserWindow({
  title: "My app",
  url: "views://mainview/index.html",
});

void win;
```

The package root, `electrobun`, currently resolves to the same main-process SDK.
Use `electrobun/view` inside browser bundles.
