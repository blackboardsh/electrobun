## Install Hutch

On macOS or Linux:

```bash
curl -fsSL https://hutch.blackboard.sh/hutch/install.sh | sh
```

On Windows PowerShell:

```powershell
& ([scriptblock]::Create((irm https://hutch.blackboard.sh/hutch/install.ps1)))
```

Restart the terminal if needed, then verify the installation:

```bash
hutch --version
```

## Create a project

Open the interactive template picker:

```bash
hutch electrobun init
```

Use the arrow keys to select a template and press Enter. Hutch downloads the
current production template catalog and creates the project.

To skip the picker, provide a project name and template:

```bash
hutch electrobun init my-app --template=hello-world
```

Use `--channel=canary` to scaffold from the canary template catalog.

## Run the app

```bash
cd my-app
hutch install
hutch run dev
```

The generated `dev` script builds the app, launches it, and watches source files
for changes. A typical project contains:

```text
my-app/
|-- src/
|   |-- bun/
|   |   `-- index.ts        # Cottontail main process
|   `-- mainview/
|       |-- index.html
|       |-- index.css
|       `-- index.ts
|-- electrobun.config.ts
|-- package.json
|-- bun.lock
`-- tsconfig.json
```

Hutch installs packages, runs scripts, bundles source, and prepares Electrobun's
native files. Cottontail executes the bundled TypeScript main process inside the
finished application.

## Build a release

```bash
hutch electrobun build --env=canary
hutch electrobun build --env=production
```

Hutch builds for the current operating system and architecture. Use native CI
runners to produce a complete cross-platform release.
