Changes since [v2.0.5](/electrobun/guides/changelog/v2-0-5/).

## Fixes

- Fixed macOS WKWebView navigation rules blocking child iframes when the main
  document has a restrictive allowlist. Native bridge access and custom preloads
  are now limited to the main frame; embedded pages should use `postMessage` to
  communicate with their parent.
- Fixed a macOS native UI deadlock when creating or destroying a UI while a
  display-frame or input callback is pending. Handler registration and removal
  no longer wait for the main thread while holding the UI lock.
- Fixed a Linux CEF navigation race where the constructor's initial page could
  overwrite an immediate `loadURL` or `loadHTML` request.
- Fixed Linux native UI windows repeatedly stealing focus from each other when
  stale focus events arrived, which could leave the app unresponsive.
