## Unattended installers

`release.headlessInstaller` adds a native command-line installer on macOS,
Windows, and Linux. It downloads and verifies the existing full update archive
without requiring zstd, tar, or a JavaScript runtime, and leaves application
startup to your provisioning tool or service manager.

Pass application-owned settings through a JSON file or stdin. The installer
writes a private `install.json` under `Paths.userData`; ordinary updates preserve
it, and reinstalling without new settings preserves its existing bytes.
Launchers now forward application arguments to every supported main-process
runtime, including native programs.

See [Unattended installation](/electrobun/guides/bundling-and-distribution/#unattended-installation)
for configuration and automation examples.

## Cross-architecture app builds

The paired Hutch CLI now supports `--arch=arm64` and `--arch=x64` for builds on
the same operating system. Zig, Bun, and devkit-pinned Cottontail apps use native
build tools while packaging the selected architecture's SDK and runtime.

Config and build hooks receive `ELECTROBUN_ARCH` for the target and
`ELECTROBUN_HOST_ARCH` for the build host. Cross builds use separate compiler
caches and generate target-specific update artifacts. Run and test the resulting
apps on the intended architecture before publishing them.

See [Cross-platform development](/electrobun/guides/cross-platform-development/)
for configuration and current limits.
