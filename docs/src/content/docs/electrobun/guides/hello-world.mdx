## Step 0: Init templates
  
  <p>This guide will walk you through building a hello world from scratch.</p>
  <p>If you'd prefer to be up and running in seconds, we offer starter templates including `hello-world`, `photo-booth`, and `multitab-browser`.</p>
  <p>Just run <strong>`hutch electrobun init`</strong> and choose the starter template you want to explore.</p>
## Step 1: Initialize your project folder
  <p>Create a new folder for your project. Let's call it `/electrobun-test`.</p>
## Step 2: Configure the project
  <p>Create a `package.json` in that folder with Electrobun as a dependency and Hutch-based development scripts:</p>
  
```javascript
{
  "name": "my-app",
  "devDependencies": {
    "@types/bun": "latest",
    "typescript": "^5.9.3"
  },
  "dependencies": {
    "electrobun": "latest"
  },
  "scripts": {
    "start": "hutch electrobun dev",
    "dev": "hutch electrobun dev --watch"
  }
}
```

  <Aside type="note">
    <strong>Note:</strong> The `electrobun/bun` import path and `@types/bun` package are retained for source compatibility; Cottontail executes the TypeScript main process.
  </Aside>
## Step 3: Install dependencies
  <p>Install the project dependencies through Hutch:</p>

```bash
hutch install
```

## Step 4: Hello World
  <p>We now have electrobun installed and a way to build and run our hello world app, let's add some code.</p>
  <p>Create a file in `src/bun/index.ts` with the following contents:</p>
  
```javascript
import { BrowserWindow } from "electrobun/bun";
const win = new BrowserWindow({
  title: "Hello Electrobun",
  url: "https://electrobun.dev",
});
```

## Step 5: Configure Electrobun
  <p>One last thing, we need to tell Hutch where our TypeScript main-process entrypoint is and how to build it. We do that by creating an `` electrobun.config.ts `` file in the root of the project.</p>
  
```javascript
export default {
  app: {
    name: "My App",
    identifier: "dev.my.app",
    version: "0.0.1",
  },
  build: {
    mainProcess: "cottontail",
    cottontail: {
      entrypoint: "src/bun/index.ts",
    },
  },
};
```

## Step 6: Run your app
  <p>With this we can now go back to our terminal and run `hutch run dev`. You should see a window pop up and load the site, and Electrobun will rebuild when your source files change.</p>
  <p>To stop running the app, press `Ctrl+C`.</p>
