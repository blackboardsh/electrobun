This guide creates a minimal Electrobun app with **Bun** as the main-process
runtime. The steps mirror the
[Cottontail Hello World](/electrobun/guides/hello-world/) — the TypeScript
SDK is identical for both JavaScript runtimes — only the
`electrobun.config.ts` selects Bun. See
[Main Process Runtimes](/electrobun/guides/native-main-process/) for every
runtime option.

## When to choose Bun

Cottontail is the default main process: it executes TypeScript and supports
the Node.js and Bun-compatible APIs used by Electrobun applications. Choose
Bun only when the application intentionally depends on the actual Bun
runtime — Bun apps get the real Bun API surface, and the two runtimes will
diverge over time. Hutch still installs packages, bundles source, and
packages the app in either configuration.

## 1. Create the project

```bash
mkdir my-app
cd my-app
```

Create `package.json`:

```json
{
  "name": "my-app",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "hutch electrobun dev --watch",
    "build": "hutch electrobun build --env=production"
  },
  "dependencies": {
    "electrobun": "latest"
  },
  "devDependencies": {
    "@types/bun": "latest",
    "typescript": "^5.9.3"
  }
}
```

Install dependencies:

```bash
hutch install
```

## 2. Add a webview

Create `src/mainview/index.html`:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width" />
    <title>Hello Electrobun</title>
  </head>
  <body>
    <h1>Hello from Electrobun</h1>
  </body>
</html>
```

## 3. Add the main process

Create `src/bun/index.ts`:

```ts
import { BrowserWindow } from "electrobun/main";

new BrowserWindow({
  title: "Hello Electrobun",
  url: "views://mainview/index.html",
  frame: {
    width: 800,
    height: 600,
    x: 200,
    y: 200,
  },
});
```

<Aside type="note">
The `electrobun/main` import path is the same TypeScript Electrobun SDK used
with Cottontail. The main-process API is documented in the
[Main API reference](/electrobun/apis/main/).
</Aside>

## 4. Configure the build

Create `electrobun.config.ts`. This is the step that selects the Bun runtime:
`build.mainProcess` is `"bun"` and the entrypoint moves to the `bun` config
field.

```ts
import type { ElectrobunConfig } from "electrobun";

export default {
  app: {
    name: "My App",
    identifier: "dev.example.my-app",
    version: "0.0.1",
  },
  build: {
    mainProcess: "bun",
    bun: {
      entrypoint: "src/bun/index.ts",
    },
    copy: {
      "src/mainview/index.html": "views/mainview/index.html",
    },
  },
} satisfies ElectrobunConfig;
```

## 5. Run the app

```bash
hutch run dev
```

Hutch builds and launches the app, then rebuilds it when watched source files
change. Press Ctrl+C to stop it.
